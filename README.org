#+title: cl-colorist

=cl-colorist= styles terminal text. It covers the named ANSI 16-color palette,
xterm-256 colors with basic-color fallbacks, 24-bit colors with derived
fallbacks, common SGR attributes, terminal capability detection, and
ANSI-aware string handling. It has no dependencies.

* Use

Basic colors are keywords:

#+begin_src lisp
(colorist:paint "ready" :foreground :green :bold t)
#+end_src

An indexed color carries a basic fallback:

#+begin_src lisp
(defparameter *accent*
  (colorist:indexed-color 114 :fallback :green))

(defparameter *status-style*
  (colorist:make-style :foreground *accent*
                       :background (colorist:indexed-color 236
                                                             :fallback :black)
                       :bold t))

(colorist:colorize " indexed when possible " *status-style*)
#+end_src

A 24-bit color renders exactly on a true-color terminal and degrades on
lesser ones. Without an explicit fallback, the closest xterm-256 index and
basic color are derived from the channels:

#+begin_src lisp
(colorist:hex-color "#fce04d")            ; index 221, :bright-yellow
(colorist:rgb-color 25 60 184)            ; index 25, :blue
(colorist:rgb-color 25 60 184
                    :fallback (colorist:indexed-color 19 :fallback :blue))
#+end_src

An indexed fallback supplies both lesser levels; a basic name fixes only the
basic level and leaves the index derived.

Reusable styles take foreground and background plus:

- =:bold=
- =:faint=
- =:italic=
- =:underline=
- =:reverse=

=colorist:sgr-sequence= and =colorist:reset-sequence= expose the raw SGR
sequences.

The 16 basic names are:

#+begin_src lisp
:black          :red          :green          :yellow
:blue           :magenta      :cyan           :white
:bright-black   :bright-red   :bright-green   :bright-yellow
:bright-blue    :bright-magenta :bright-cyan  :bright-white
#+end_src

* Capability selection

=colorist:terminal-color-level= returns =:none=, =:basic=, =:indexed=, or
=:truecolor=. It honors:

- =NO_COLOR=
- =TERM=dumb=
- true-color =COLORTERM= values (=truecolor=, =24bit=)
- =TERM=*-256color= and 256-color =COLORTERM= values

Bind =colorist:*color-level*= to override detection for a dynamic scope:

#+begin_src lisp
(let ((colorist:*color-level* :none))
  (colorist:paint "always plain here" :foreground :red))
#+end_src

An explicit =:level= argument to rendering functions takes precedence over the
dynamic override.

* ANSI-aware text

- =colorist:strip-ansi= removes CSI, OSC, other control-string, C1, and
  ordinary escape sequences
- =colorist:visible-length= counts Lisp characters; those sequences have
  width zero
- =colorist:ansi-control-end= exposes the same parser to renderers that keep
  controls while slicing visible text

* Development

#+begin_src sh
./script/bootstrap
./script/check
./script/check --fix
#+end_src

=./script/bootstrap= sets up =.qlot/= from the =qlfile=.
=./script/check= runs the tests, then checks the source with
[[https://github.com/lambda-symbolics/cheque][cheque]] as =cheque.sexp=
configures it. =--fix= skips the tests and repairs what cheque can repair.
cheque and its tools are development dependencies: =checks/qlfile= lists them,
and the check installs them on first use into =~/.cache/cheque/tools/=.

The check runs the same tests as this form in a REPL:

#+begin_src lisp
(asdf:load-asd #P"/path/to/cl-colorist/cl-colorist.asd")
(asdf:test-system :cl-colorist)
#+end_src
